# Anchor plugin for Cursor

[Anchor](https://anchor.cc) is a shared drive where Cursor builds and shares apps and artifacts, such as interactive presentations and documents, that run on real data from SQL tables and MCP servers. It also hosts your other files, such as HTML, Markdown (MD), SVG, PNG, and MP4, each with a link you can send to your team.

This plugin adds the Anchor MCP server (`https://mcp.anchor.cc/mcp`) to Cursor.

## Install

Follow the steps at [anchor.cc/supported-agents/cursor](https://anchor.cc/supported-agents/cursor).

## Configuration

There is nothing to configure. Cursor opens the Anchor sign-in page the first time you connect. Sign in once, with no API keys. Cursor only touches what you can access.
