# Anchor plugin for Cursor

[Anchor](https://anchor.cc) is a shared drive for you and your agents. This plugin adds the Anchor MCP server (`https://mcp.anchor.cc/mcp`) to Cursor, so Cursor can securely create, host, and share apps, presentations, documents, SQL tables, and files.

## Install

Follow the steps at [anchor.cc/supported-agents/cursor](https://anchor.cc/supported-agents/cursor).

## Configuration

There is nothing to configure: no API keys, no environment variables. Cursor opens the Anchor sign-in page the first time you connect. Sign in once, and Cursor only ever touches what you can access.
